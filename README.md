# Loan OK Connect

A full-stack loan application platform that connects users with financial solutions. Built from scratch as a production-ready fintech application.

## 🚀 Live Demo
[https://loanok.in](https://loanok.in)

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Auth0
- **Email Service:** EmailJS
- **Deployment:** Vercel, GoDaddy (Domain)

## ✨ Key Features

### User Features
- Secure authentication and authorization using Auth0
- Loan application submission with real-time status tracking
- Unique application ID generation for status monitoring
- Email notifications for application updates

### Admin Features
- Admin dashboard for document verification
- Centralized loan application management
- User management and application progress tracking

### Technical Highlights
- RESTful API architecture with Node.js and Express.js
- Responsive UI built with React.js and Tailwind CSS
- SEO optimized with meta tags and structured data
- Optimized React components for improved performance

## 📊 Project Impact
- Production application serving real customers
- Processed real loan applications
- Solo development: backend, frontend, database, and deployment
